# Notifications — NestJS / TypeScript

Scaffold oficial, sin implementación de envío ni endpoints del contrato todavía. Sin Observe, DB ni SMTP.

Instalar dependencias con `bun install --frozen-lockfile`.

Desde esta carpeta: `bun run lint`, `bun run build`, `bun run test`, `bun run test:e2e`. Para levantar solo el scaffold: `PORT=4006 bun run start:dev`. Aún responde únicamente el saludo generado.
